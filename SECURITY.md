# Security Policy

## Supported baseline

Security fixes are applied to the default branch. Keep deployments on the latest verified commit and do not expose the local Compose profile to the public internet.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or a working attack in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option in the Security tab. If it is not enabled, contact the repository owner through GitHub and request a private reporting channel before sharing technical details.

## Responsible use

- Use the platform only with applicable legal authorization and explicit, informed consent.
- Do not add hidden collection of location, screen contents, microphone, camera, messages, or hardware identifiers.
- Keep the admin control plane private and secrets outside source control.
- Treat the local JSON stores and local audit file as development-only; production requires shared protected storage, external backups, and an approved retention policy.
